## 一、正样例检查清单（每条祝福逐项过）

1. 至少结合一条人物特征，或明显贴合关系与日子；
2. 不出现任何年龄、岁数、「X 岁」「大寿」表述；
3. 有自称时末尾另起一行落款「——{自称}」；无自称时不落款、无署名暗示；
4. 纪念日仅在给出周年数时出现「N 周年」，只给名称时不杜撰年份；
5. 节日祝福体现节日主题与典型情境；
6. 不编造未提供的职业、爱好、经历；
7. 30–90 字、完整可直接复制发送，无编号、无引号包裹；
8. 通用版节日（person=null）不针对具体某个人，也不空泛喊口号。

## 三、本批抽检记录

### case1 妈妈生日（正样例；payloads/case1-birthday.json）

入参：生日 / 家人 / 特征「爱养花、今年刚退休、喜欢早起爬山」/ 称呼妈妈 / 自称儿子小明 / count=3。

当次输出：

1. 妈妈，生日快乐！退休后您把日子过得有滋有味，早起爬山、侍弄花草，看着您精神头这么足，我心里特别踏实。愿您身体硬朗，天天都有好心情。<br>——儿子小明
2. 妈，祝您生日快乐。以前您总为我们忙，如今退休了，终于能好好养养花、爬爬山。您爱惜身体、按时吃饭，就是我最大的心愿。<br>——儿子小明
3. 妈妈，生日快乐！想到您清晨在山路上走着、回家又给花浇水的样子，就觉得这样的日子真好。愿您往后每一天都松快自在，我常回来陪您。<br>——儿子小明

判定：✅ 三条全部融合 2 条以上特征；家人语气；无年龄；三条均按规则另起一行落款；无编号无引号。

### case2 客户无特征合作纪念日（正样例；payloads/case2-client-notrait.json）

入参：纪念日「合作纪念日」/ anniversaryYears=5 / 客户 / 无特征 / 称呼王总 / **无自称** / count=3。

当次输出：

1. 王总，合作五年，一路走来感谢您的信任与支持。愿我们继续并肩前行，把每一件事做扎实，也祝您事业顺遂、诸事称心。
2. 王总，五周年了。这份合作的默契来之不易，能被您一直认可，是我们的荣幸。祝您工作顺利、身体康健，也期待下一个五年继续同行。
3. 王总，值此合作五周年之际，谨向您表达诚挚的谢意。感谢这些年来的理解与配合，愿我们往后的合作更加顺畅长久，祝您一切安好。

判定：✅ 客户语气得体有分寸；无特征未编造爱好职业；周年数出现且只围绕五周年；**三条均无落款、无署名暗示**；称呼自然使用。

### case4 通用版元旦（正样例；payloads/case4-generic-festival.json）

入参：节日「元旦」/ person=null / count=3。

当次输出：

1. 新的一年翻开第一页，愿你把去年的疲惫留在昨夜，把想做的事一件件写进日历，愿日子清清爽爽，心里踏踏实实。元旦快乐。
2. 钟声敲过，日历换了新的一本。愿你新年里睡得好、吃得香，想见的人都能见到，想去的远方都来得及去。元旦快乐，万事顺遂。
3. 元旦这天，天还是冷的，心可以先热起来。愿新的一年少些为难自己的时刻，多些被温柔对待的瞬间，走得慢一点也没关系。

判定：✅ 不针对任何具体个人；三条均扣「新年首日/辞旧迎新」主题，非万能口号；无落款（无自称）。
